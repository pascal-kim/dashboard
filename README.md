# 사업예산 대비 집행 대시보드

## 실행 방법 (Windows)
1. Python 3.11 이상 설치: https://www.python.org/downloads/
2. 이 폴더에서 주소 표시줄에 `cmd` 입력 후 Enter
3. `python -m pip install -r requirements.txt`
4. `python -m streamlit run app.py`
5. 브라우저에서 예산 파일과 집행 파일을 각각 업로드

## 입력 파일
- 예산 파일: 상세 예산내역 시트. 기본 선택은 `예산내역-whatif...` 시트, 제목 행은 엑셀 2행으로 가정합니다.
- 집행 파일: 전표 상세 시트. `전기일`, `금액(현지 통화)`, `지출 부서`, `과제번호`, `자금`, `연구재단 비목`, `계정과목` 열이 필요합니다.

## 주요 기능
- 예산액, 누적 순집행액, 단순 잔액, 집행률
- 전기일 기준 월별 순집행액 그래프
- 영역별 예산·집행 비교
- 부서/과제/자금/비목 필터
- 예산과 연결되지 않은 집행 조합 점검

## 유의사항
- 예산 연결은 부서명, 과제번호, 자금코드, 연구재단비목, 계정코드가 일치하는 조합으로 계산합니다.
- 집행일은 `전기일`을 사용하고, 환입/취소 등 음수 금액은 원본 부호를 유지합니다.
- 미연결 집행은 월별 집행액에는 포함되지만 예산 대비 잔액/집행률의 연결 집계에는 반영되지 않을 수 있으므로 검증 영역에서 확인해야 합니다.
- 잔액은 단순 예산액-순집행액입니다. 실제 회계 잔액과 다를 수 있습니다.
